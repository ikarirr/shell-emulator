# Эмулятор оболочки ОС

Учебный проект по дисциплине "Конфигурационное управление".

## Автор

Типалова Карина, группа УНБО-04-25

## Описание

Эмулятор командной строки UNIX-подобной ОС с виртуальной файловой системой (VFS). Проект разрабатывается поэтапно.

## Текущий статус

**Этап 1. REPL** — выполнен.

- Консольный интерфейс (CLI).
- Приглашение содержит имя VFS (my-vfs>).
- Парсер с поддержкой кавычек.
- Команды-заглушки: ls, cd.
- Команда exit.
- Обработка ошибок.

**Этап 2. Конфигурация** — выполнен.

- Параметры командной строки: --vfs, --script.
- Стартовый скрипт выполняет команды по очереди.
- При первой ошибке выполнение останавливается.
- Отладочный вывод параметров при запуске.

## Структура проекта

shell-emulator/
- src/main.py — исходный код эмулятора
- scripts/startup.txt — стартовый скрипт для тестирования
- tests/ — тесты (будут добавлены)
- README.md — документация
- .gitignore — игнорируемые файлы

## Команды для запуска

Интерактивный режим:

cd src
python main.py

С параметром VFS:

cd src
python main.py --vfs ../vfs.json

Со стартовым скриптом:

cd src
python main.py --script ../scripts/startup.txt

## Примеры использования

=== Параметры запуска эмулятора ===

Скрипт: (не задан)
