\# Эмулятор оболочки ОС



Учебный проект по дисциплине "Конфигурационное управление".



\## Автор



Типалова Карина, группа УНБО-04-25



\## Описание



Эмулятор командной строки UNIX-подобной ОС с виртуальной файловой системой (VFS). Проект разрабатывается поэтапно в соответствии с заданием.



\## Текущий статус



\*\*Этап 1. REPL\*\* — выполнен.



\- Реализован консольный интерфейс (CLI).

\- Приглашение к вводу содержит имя VFS (my-vfs>).

\- Парсер поддерживает аргументы в кавычках (одинарных и двойных).

\- Реализованы команды-заглушки: ls, cd.

\- Реализована команда exit.

\- Обрабатывается ошибка «команда не найдена».

\## Команды для запуска



Запуск эмулятора:



cd src

python main.py



Примеры использования:



my-vfs> ls

ls: \[]



my-vfs> ls -la /home

ls: \['-la', '/home']



my-vfs> cd "Моя папка"

cd: \['Моя папка']



my-vfs> hello

hello: команда не найдена



my-vfs> exit

Выход из эмулятора.
